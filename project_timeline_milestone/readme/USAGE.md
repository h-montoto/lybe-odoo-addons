1. Set a deadline on the milestones of a project.
2. Open the tasks of the project in the *Timeline* view. The default grouping
   is by project, which draws each milestone in the row of its project.
3. Link tasks to milestones. A task is highlighted when it is planned to end
   after the deadline day of its milestone, unless the task is done or
   cancelled or the milestone is already reached. The comparison uses the
   timezone of the user.
