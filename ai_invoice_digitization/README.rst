This module extracts data from PDF vendor bills, including line items,
using AI, either on demand or automatically when a bill arrives by
email.

- Multi-provider AI support: OpenAI, Anthropic, Google Gemini and
  DeepSeek.
- Extracts vendor, invoice number, date, due date, amounts, taxes and
  line items.
- Fuzzy matching against vendors and products already in Odoo.
- Purchase taxes are assigned from the vendor's fiscal position.
- Manual trigger button on any vendor bill with a PDF attachment.
- Automatic trigger on incoming email.
- Review mode before saving the extracted data.

Installation
============

This module needs the ``pypdf`` Python library in the environment Odoo
runs in:

.. code:: bash

   pip install pypdf

If ``pymupdf`` is also installed, it is tried first, since it usually
yields a better text extraction; ``pypdf`` is used as the fallback.

Configuration
=============

Go to *Accounting → Configuration → Settings*, section *Digitalización
IA de Facturas*, and set:

- the AI provider, its API key and the model to use (an API key for at
  least one supported provider is required);
- whether bills received by email are digitized automatically;
- whether extracted bills are confirmed without human review, and the
  minimum confidence threshold required for it.

Usage
=====

- **Manually**: open a vendor bill with a PDF attachment and click
  *Digitalizar con IA*. Review the extracted data and confirm it.
- **By email**: send the PDF bill to the mail alias created by the
  module; a draft vendor bill is created and filled in automatically.
