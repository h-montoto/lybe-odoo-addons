1. Open a sale order (Sales > Orders) or create a new one.
2. Go to the "Other Info" tab.
3. Set the "Cliente Final" (End Customer) field to the partner that is the
   real recipient of the work, regardless of the partner being invoiced.
4. The same field is available on customer invoices (Accounting >
   Customers > Invoices), in the "Other Info" tab.
5. The field can also be displayed as an optional column in the sale
   order list view.
6. Changes to this field are tracked in the record's chatter.
